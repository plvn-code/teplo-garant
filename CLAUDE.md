Client site for **Teplogarant / Тепло Гарант** — importer of heating radiators since 2000: designer & steel radiators, towel warmers, valves, heating elements (IRSAP, Zehnder, Vasco, Stelrad — official distributor —, Quinn, Purmo, Radson, Terma…). Head office + warehouse in смт Наварія (10 km from Lviv, автошлях Т1416), showrooms in Kyiv and Ivano-Frankivsk. +38 098 935 15 71, info@teplogarant.in.ua, Пн–Пт 9–18, Сб 9–14. Instagram/Facebook @teplogarantlv, Telegram @Teplogarantlv. Old shop: OpenCart (uk at `/`, ru at `/ru/`).

Brief from the user: expensive, quality redesign in the style of our sites (aluabri, autohim, superio), animations in moderation, the client's colours **red + blue + white** (logo is a navy #2e386b → red #e01e25 vertical gradient), photos in excellent quality, all info from the old site and socials.

**Talk to the user in Russian.** Site copy is **Ukrainian only** (`lang="uk"`, ’ apostrophes, «» quotes). Read `docs/STATUS.md` first (open client questions). **The user is short on disk space**: don't keep raw downloads, don't run a separate `npm install` (see below).

## Commands
```bash
npm run build && npm start               # production on :3014 (dev: npm run dev)
kill $(lsof -ti tcp:3014 -sTCP:LISTEN)   # restart: only our port, only LISTEN (otherwise it also kills Chrome)
npm run lint && npx tsc --noEmit         # must stay clean
open -a "Google Chrome" http://localhost:3014
research/.venv/bin/python -I scripts/catalog.py .   # rebuild src/data/catalog.json + public/images (needs originals/, see below)
```
`node_modules` is a **symlink to ~/Desktop/autohim/node_modules** (identical package.json deps) to save ~400 MB. If deps ever diverge, replace the symlink with a real install. `research/.venv` → `~/Desktop/aluabri/research/.venv` (Pillow, numpy).

## Stack
Next.js 15 App Router · React 19 · TypeScript strict · plain CSS (`src/app/globals.css`: shared base from autohim, re-tokened, then a «TEPLOGARANT components» block at the end) · next/font (Unbounded, Manrope, JetBrains Mono) · no animation libraries (IntersectionObserver + rAF: `src/lib/motion.ts`, `src/components/Effects.tsx`). All motion respects `prefers-reduced-motion`. Images are pre-built WebP, so `<img>` is used on purpose.

Palette: deep navy base, red = action/heat (CTA gradient blue→red like the logo), blue = selection, white = `.section-light` sections (token override) + white product stages. Accent text `--cyan` is actually a warm coral (#ff6a5c); `--ice` is the light brand blue.

## Data pipeline
The old site blocks scripted requests after ~270 pages (Cloudflare 403 for curl, any UA); images are not blocked. What worked: pages via curl until the block, the rest through the Playwright browser (`fetch` inside the page, results saved as **one** JSON download → moved from ~/Downloads into research/). Never trigger one browser download per page again (Chrome stalls and it litters ~/Downloads).
- `research/sitemap.json` (from /sitemap.xml) · `research/products.json` (284 parsed products: prices, old prices, stock, specs, variants, description, reviews, YouTube id, gallery URLs) · `research/blog.json` + `research/blog-text.json` (47 articles). Raw HTML was deleted after parsing.
- `scripts/fetch_pages.py` / `scripts/parse_pages.py` — crawler + parser for OpenCart product pages (kept for reference).
- `scripts/fetch_photos.py` — downloads original photos (max 5/product) into `originals/` (deleted after building to save space; rerun to rebuild images).
- `scripts/catalog.py` — sections (old slug kept for redirects), brands, subtypes, colour/connection normalisation, ASCII slugs (`oldSlug` keeps the original, some had a Cyrillic «і»), images: packshots trimmed + recentred on pure white 1400 px + unsharp; interiors ≤1200 px. Writes `public/images/p/<id>-<n>.webp` (+ `<id>-<n>s.webp` 640 px for the first two) and `public/images/blog/<slug>.webp`. `research/image-meta.json` caches kind/aspect.

Old URLs redirect (next.config.ts): `/<product>` and `/ru/<product>` → `/tovar/…`, category slugs → `/katalog/…`, brand slugs → `/brendy/…`, about/shipping/contact/sale → new pages. Search indexing stays off until `NEXT_PUBLIC_SITE_LIVE=1`.
